## PoC Hayhooks + Chainlit

This repo provides a minimal Hayhooks setup with a Chainlit UI client.
The pipeline definition is generated by [pipelines/src/build_agent.py](pipelines/src/build_agent.py)
and written into [pipelines/definitions/router_agent.yaml](pipelines/definitions/router_agent.yaml).

### Requirements

- Docker
- Ollama running locally (default: http://localhost:11434)

### Quick start

Copy the example environment file and set your Ollama settings if needed:

```bash
cp .env.example .env
```

```bash
./start.sh
```

Then open:

- Hayhooks: http://localhost:1416
- Chainlit: http://localhost:8000

### How it works

1. `start.sh` runs `pipelines/src/build_agent.py` to generate the YAML pipeline.
2. The generated Hayhooks definition lives in `pipelines/definitions/router_agent.yaml`.
3. Docker Compose starts Hayhooks and Chainlit together.
4. Chainlit posts user messages to `http://localhost:1416/router_agent/run`.

### Configuration

Copy `.env.example` to `.env` if you want to set `OLLAMA_URL` and `OLLAMA_MODEL` locally.
Chainlit and Hayhooks use the settings from `docker-compose.yml`.
